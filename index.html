Jak propojit HTML s CSS

Jsou tři způsoby, jak propojit CSS s HTML:


  1. 1. Použít externí css soubor a propojit ho pomocí elementu <link> v hlavičce HTML souboru
  2. 2. Použít <style> element v hlavičce html souboru
  3. 3. Použít atribut style v HTML elementu

Ukázka

  1. 1. Externí:

    <head>

    <link rel="stylesheet" href="mystyle.css">

    </head>

  2. 2. V Hlavičce:

    <head>

    <style>

    body {

     background-color: blue;

    }

    </style>

    </head>

  3. 3. V Elementu:

    <p style="color:red;"> Text </p>

Jak propojit JS s HTML

Propojit Javascript s HTML lze dvěma způsoby:


  1. 1. Propojit pomocí <script> tagu odkaz na externí JavaScript soubor v hlavičce HTML souboru
  2. 2. Použít JavaScript kód přímo v HTML souboru pomocí tagu <script>, který dáváme vždy na konec <body>

Ukázka Kódu

  1. 1. Externí soubor:

    <head>

    <script src="script.js"></script>

    </head>


  2. 2. JavaScript integrovaný do HTML:

    <body>

    <--! HTML kód -->

    <script src="script.js"></script>

    </body>

Základy JavaScriptu

Proměnné

Proměnné slouží k ukládání dat pod vlastními názvy, se kterými potom můžeš v programu pracovat (např. text, čísla, seznamy). V JavaScriptu existují dva základní druhy proměnných: let a const.


U proměnné let se hodnota může měnit.


U proměnné const se hodnota po jejím deklarování změnit nemůže.

Ukázka Kódu

  1. 1. Proměnná let:

    let jmeno = "Jan"

    jmeno = "Petr"


  2. 2. Proměnná const:

    const vek = 25;

    vek = 30; // vypíše chybu

console.log()

Console.log() je funkce, která vypisuje hodnoty do vývojářské konzole v prohlížeči.

Používá se hlavně při učení a ladění kódu – můžeš si ověřit, co se děje v programu.

Ukázka Kódu

console.log("Ukázkový text");

Podmínky

Podmínky umožňují spouštět různé části kódu podle toho, jestli je nějaká podmínka splněná.

Používají se všude tam, kde program musí „rozhodovat“, např. kontrola věku, přihlášení...

Ukázka Kódu

let vek = 18;

if (vek => 18) {

 console.log("Přístup povolen");

}

else {

 console.log("Nejsi plnoletý, přístup odepřen");

}

Cyklus (for)

Cyklus (anglicky "loop") opakuje určitý blok kódu vícekrát.

Používá se např. pro procházení pole (array) nebo opakování akce po určitý počet pokusů.

Ukázka Kódu

for (let i = 0; i < 3; i++) {

 console.log("Opakování: ", i);

}

Funkce

Funkce je blok kódu, který je možné "zavolat" kdykoli je potřeba. Pomáhá rozdělit program na menší části.

Používá se pro znovupoužití kódu a lepší organizaci.

Ukázka Kódu

function pozdrav(jmeno) {

 console.log("Ahoj " + jmeno);

}

pozdrav("Jan");

Arrow funkce

Arrow funkce poskytují modernější a kratší zápis funkce.

Využívá se často u jednoduchých funkcí nebo jako callback (např. u událostí).

Ukázka Kódu

const pozdrav = (jmeno) => {

 console.log("Ahoj " + jmeno);

};
