Jak propojit HTML s CSS

Jsou tři způsoby, jak propojit CSS s HTML:


  1. Použít externí css soubor a propojit ho pomocí elementu <link> v hlavičce HTML souboru
  2. Použít <style> element v hlavičce html souboru
  3. Použít atribut style v HTML elementu

Ukázka

  1. 1. Externí:

    <head>

    <link rel="stylesheet" href="mystyle.css">

    </head>

  2. 2. V Hlavičce:

    <head>

    <style>

    body {

     background-color: blue;

    }

    </style>

    </head>

  3. 3. V Elementu:

    <p style="color:red;"> Text </p>

Syntax a Selektory

Syntax

Pravidlo CSS se skládá ze selektoru a deklaračního bloku:


  • Selektor ukazuje, jakou třídu, id nebo element chcete stylovat.
  • Blok deklarací obsahuje deklarace oddělené středníky.
  • Deklarace obsahuje vlastnost CSS a její hodnotu oddělenou dvojtečkou.
  • Bloky deklarací jsou uzavřeny do složených závorek.

Ukázka

Selektor

body

Vlastnost : Hodnota

{background-color: blue;}

Selektory

CSS selektory se používají k výběru prvků HTML, které chcete stylovat.

Níže je seznam několika základních typů:


  • Selektor elementu, který vybírá HTML prvky na základě jejich názvu.
  • ID selektor, který používá atribut id HTML elementu k výběru konkrétního elementu. ID elementu je v rámci stránky jedinečné.
  • Selektor Třídy vybírá prvky HTML se specifickým atributem třídy.
  • Univerzální selektor, který vybírá všechny elementy na stránce.

Selektory je také možné seskupovat. Oddělujeme je čárkou.

Ukázka

  • Dle Elementu:

    element {}

  • Dle ID:

    #id {}

  • Dle Třídy:

    .class {}

  • Univerzální:

    * {}


  • Seskupené selektory

    selektor1, selektor2, selektor3, ... {}

Základní vlastnosti

Barvy a Pozadí

V CSS se barvy určují pomocí předdefinovaného názvu barvy nebo pomocí hodnoty RGB, HEX, HSL, RGBA nebo HSLA

Můžeme upravit například barvu:


  • Pozadí
  • Textu
  • Ohraničení

Seznam všech předdefinovaných barev

Ukázka

  • Barva Pozadí:

    background-color:blue

  • Barva Textu:

    color:blue

  • Barva Ohraničení:

    border:2px solid blue


  • Možnosti definování barev:

    color:blue

    color:rgb(255, 99, 71)

    color:#001047

    color:hsl(147, 50%, 47%)

    V těchto je také možné definovat průhlednost:

    color:rgba(255, 99, 71, 0.5)

    color:hsla(9, 100%, 64%, 0.5)

Border

Vlastnosti ohraničení umožňují nastavit styl, velikost a barvu ohraničení.

Styly ohraničení:


  • dotted - Tečkované ohraničení
  • dashed - Přerušované ohraničení
  • solid - Plné ohraničení
  • double - Dvojité ohraničení
  • groove - 3D drážkované ohraničení
  • ridge - 3D vroubkované ohraničení
  • inset - 3D zastouplé ohraničení
  • outset - 3D vystouplé ohraničení
  • none - Bez ohraničení
  • hidden - Skryté ohraničení

Styly je možné kombinovat.

Šířku ohraničení je možné nastavit na specifickou hodnotu (např. px) nebo pomocí tří předdefinovaných hodnot: thin, medium a thick

Styly a šířky mohou mít jednu až čtyři hodnoty (Nahoře, Vpravo, Dole, Vlevo).

Je také možné specifikovat jednu stranu ohraničení. Např. border-top-radius


Barvy ohraničení jsou vysvětleny v sekci barvy.

Ukázka

  • Zápis v kódu:

    border-style:dotted

    border-style:dotted solid double dashed

    border-width:medium

    border-width:25px 10px 4px 35px

  • Ukázka:

    dotted dashed solid double

    groove

    ridge

    inset

    outset

Zakulacené rohy

Zakulacené rohy můžeme vytvořit pomocí vlastnosti border-radius

Může mít jednu až čtyři hodnoty (Nahoře, Vpravo, Dole, Vlevo).


Pro jednotlivé rohy lze také použít the border-top-left-radius, border-top-right-radius, border-bottom-right-radius a border-bottom-left-radius

Ukázka

  • border-radius:5px

    border-radius:5px 10px 15px 10px

Výška a Šířka

Tyto vlastnosti nastavují, jako výšku a šířku element bude mít.

Mají následující hodnoty:


  • auto - Základní hodnota. Prohlížeč spočítá výšku a šířku.
  • Specifická hodnota (např. px)
  • % - Procenta
  • initial - Nastaví šířku nebo výšku na základní hodnotu.
  • inherit - Výška nebo šířka bude převzata z nadřazené hodnoty.

Ukázka

  • Výška:

    height:auto

  • Šířka:

    width:auto

Texty a Fonty

Texty

U textu můžeme nastavit barvu, zarovnání a dekoraci.

O barvě textu je možné se více dozvědět v sekci barvy.

Možnosti zarovnání textu:


  • left
  • right
  • center
  • justify

Při nastavení „justify“ se každý řádek natáhne tak, aby měl stejnou šířku a levý a pravý okraj byly rovné.

Je několik možností dekorace textu:


  • overline
  • line-through
  • underline

Můžeme také změnit barvu, styl nebo tloušťku dekorace.

Styly dekorace:


  • solid
  • double
  • dotted
  • dashed
  • wavy

Ukázka

  • Zarovnání textu:

    text-align:left

    text-align:right

    text-align:center

  • Dekorace textu:

    text-decoration-line:overline

    text-decoration-line:line-through

    text-decoration-line:underline

  • Vlastnosti dekorace textu:

    text-decoration-color:black

    text-decoration-style:wavy

    text-decoration-thickness:5px

Fonty

V CSS můžeme také nastavit vlastní písmo.


Je možné nastavit několik písem jako „záložní“ systém. Pokud prohlížeč nepodporuje první písmo, zkusí použít další. Názvy písem by měly být odděleny čárkou.


Dále lze u písem nastavit jejich velikost a také styl (normal,italic,...)

Ukázka

  • Nastavení písma:

    font-family: "Times New Roman", Times, serif

  • Styl písma:

    font-style: italic

  • Velikost písma:

    font-size: 16px

Box Model

Box Model

V CSS se termín „box model“ používá, když se mluví o webdesignu a rozvržení.

Skládá se ze čtyř částí (od nejvnitřnější k nejvnější):


  • Content - Obsah (Obrázky, text, atd.)
  • Padding - Prázdná oblast mezi obsahem a ohraničením (Border)
  • Border - Ohraničení obsahu a paddingu
  • Margin - Prázdná oblast okolo ohraničení.

Ukázka

Content, Padding, Border, Margin

Margin a Padding

Margin se používá k vytvoření prostoru kolem prvků. Definují vzdálenost mezi okrajem elementu a okolními elementy.


Padding se používá k vytvoření prostoru kolem obsahu elementu, uvnitř definovaných okrajů.


Margin a Padding je také možné nastavit na jednotlivé strany:

  • margin/padding-top
  • margin/padding-left
  • margin/padding-right
  • margin/padding-bottom

Nebo pomocí čtyř hodnot. (top,right,bottom,left)

Ukázka

  • Margin:

    margin:20px

  • Padding:

    padding:20px

  • Specifické nastavení:

    margin:12px 4px 2px 4px

Jak propojit JS s HTML

Asociovat Javascript s HTML lze dvěma způsoby:


  1. 1. Propojit pomocí <script> tagu odkaz na externí JavaScript soubor v hlavičce HTML souboru
  2. 2. Použít JavaScript kód přímo v HTML souboru pomocí tagu <script>, který dáváme vždy na konec <body>

Ukázka Kódu

  1. 1. Externí soubor:

    <head>

    <script src=​"script.js"></script>

    </head>


  2. 2. JavaScript integrovaný v HTML:

    <body>

    <--! HTML kód -->

    <script>

     <--! Javascript kód -->

    </script>

    </body>

Základy JavaScriptu

Proměnné

Proměnné slouží k ukládání dat pod vlastními názvy, se kterými lze potom v programu dále pracovat (např. text, čísla, seznamy). V JavaScriptu existují dva základní druhy proměnných: let a const.


  1. u proměnné let se hodnota může měnit.

  2. u proměnné const se hodnota po jejím deklarování změnit nemůže.


Po klíčových slovech let nebo const následuje název proměnné jakýkoli si zvolíte, znaménko '=' a hodnotu kterou jí chcete přiřadit. Středníkem (;) vždy zakončujeme příkaz.

Ukázka Kódu

  1. 1. Proměnná let:

    let jmeno = "Jan";

    jmeno = "Petr";


  2. 2. Proměnná const:

    const vek = 25;

    vek = 30; // vypíše chybu

console.log()

Console.log() je funkce, která vypisuje hodnoty do vývojářské konzole v prohlížeči. Používá se hlavně při učení a ladění kódu – můžete si tak ověřit, co se děje v programu.

Mezi závorky vždy vložíme název proměnné či jakoukoli jinou hodnotu kterou chceme vypsat.

Ukázka Kódu

  1. 1. Vypsání vlastní hodnoty

    console.log(​"Ukázkový text");


  2. 2. Vypsání hodnoty z proměnné

    const vesnice = "Brno";

    console.log(vesnice);

Podmínky

Podmínky umožňují spouštět různé části kódu podle toho, jestli je nějaká podmínka splněná.

Používají se všude tam, kde program musí „rozhodovat“, např. kontrola věku, přihlášení...


Po slovu if následuje v závorkách podmínka a v hranatých závorkách kód který se spustí pokud je podmínka platná. Pro více podmínek se používá (ale není povinný) příkaz else if a else pokud žádná z podmínek nemá být pravdivá.

Ukázka Kódu

let vek = 18;

if (vek => 18) {

 console.log(​"Přístup povolen");

} else if (vek > 120) {

 console.log(​"Zadejte platný věk");

} else {

 console.log(​"Nejsi plnoletý, přístup odepřen");

}

Cyklus (for)

Cyklus (anglicky "loop") opakuje určitý blok kódu vícekrát.

Používá se např. pro procházení pole (array) nebo opakování akce po určitý počet pokusů.

Ukázka Kódu

for (let i = 0; i < 3; i++) {

 console.log(​"Opakování: ", i);

}

Funkce

Funkce je blok kódu, který je možné "zavolat" kdykoli je potřeba. Pomáhá rozdělit program na menší části.

Používá se pro znovupoužití kódu a lepší organizaci.

Ukázka Kódu

function pozdrav(jmeno) {

 console.log(​"Ahoj " + jmeno);

}

pozdrav("Jan");

Arrow funkce

Arrow funkce poskytují modernější a kratší zápis funkce.

Využívá se často u jednoduchých funkcí nebo jako callback (např. u událostí).

Ukázka Kódu

const pozdrav = (jmeno) => {

 console.log(​"Ahoj " + jmeno);

};

Pole

Pole (angl. "array") je seznam hodnot uložených v jedné proměnné.

Používá se pro práci s více daty, např. seznam uživatelů, produktů...

Ukázka Kódu

let ovoce = ["jablko", "banán", "pomeranč"];

 console.log(​ovoce[1]);

Objekt

Objekty ukládají data ve formě klíč-hodnota, přičemž jeden objekt může mít libovolný počet vlastností.

Používají se tedy pro reprezentaci složitějších dat (např. uživatel s více vlastnostmi).

Ukázka Kódu

let uzivatel = {

 jmeno: "Tomáš",

 vek: 25

};


console.log(​uzivatel.vek);

document.querySelector()

document.querySelector() vybírá první HTML element, který odpovídá zadanému CSS selektoru.

Používají se pro propojení Javascriptu s HTML (tzv. práce s DOM).

Ukázka Kódu

let nadpis = document.querySelector("h1");

textContent

Vlastnost, která nastavuje nebo čte text uvnitř elementu.

Používá se pro dynamickou změnu textu na stránce.

Ukázka Kódu

let p = document.querySelector("p");

p.textContent = "Nový text";
