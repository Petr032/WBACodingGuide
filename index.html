Základy HTML

<html>

Popis:
Kořenový (root) element celé HTML stránky. Všechen obsah webu musí být uvnitř tohoto tagu. Prohlížeč díky němu ví, že pracuje s HTML dokumentem.


Jak se využívá:
Používá se vždy jednou na začátku dokumentu a obaluje celý obsah stránky.

Ukázka Kódu

<html lang="cs">
</html>

<head>

Popis:
Obsahuje metadata o stránce – tedy informace, které se nezobrazují přímo uživateli (např. název stránky, propojení na CSS, znaková sada).


Jak se využívá:
Používá se pro nastavení stránky a připojení externích souborů (CSS, fonty, skripty).

Ukázka Kódu

<head>

<meta charset="UTF-8">

<title>Moje stránka</title>

<link rel="stylesheet" href="style.css">

</head>

<body>

Popis:
Obsahuje veškerý viditelný obsah stránky – texty, obrázky, tlačítka atd.


Jak se využívá:
Sem patří vše, co má uživatel vidět a s čím může interagovat.

Ukázka Kódu

<body>

<h1>Ahoj světe</h1>

<p>Toto je můj web.</p>

</body>

Rozdělení stránky

<header>

Popis:
Záhlaví stránky nebo sekce. Obvykle obsahuje logo, název webu nebo navigaci.


Jak se využívá:
Používá se na začátku stránky nebo jednotlivých sekcí pro důležité úvodní informace.

Ukázka Kódu

<header>

<h1>Moje stránka</h1>

<nav>

<a href="#"> Domů </a>

<a href="#"> Kontakt </a>

</nav>

</header>

<footer>

Popis:
Zápatí stránky nebo sekce. Obsahuje doplňující informace, jako jsou kontakty, copyright nebo odkazy.


Jak se využívá:
Používá se na konci stránky nebo sekcí.

Ukázka Kódu

<footer>

<p>&copy; 2026 Moje stránka</p>

</footer>

<main>

Popis:
Hlavní obsah stránky. Měl by obsahovat unikátní obsah dané stránky (ne navigaci, ne patičku).


Jak se využívá:
Používá se pro oddělení hlavního obsahu od ostatních částí jako header nebo footer. Na stránce by měl být pouze jeden.

Ukázka Kódu

<main>

<h2>Vítej na mém webu</h2>

<p>Tady je hlavní obsah stránky.</p>

</main>

<section>

Popis:
Slouží k logickému rozdělení obsahu stránky do tematických celků (sekcí).


Jak se využívá:
Používá se, když má obsah smysluplnou strukturu (např. kapitoly, části článku). Každá sekce by měla mít ideálně nadpis.

Ukázka Kódu

<section>

<h2>O nás</h2>

<p>Jsme firma zabývající se tvorbou webů.</p>

</section>

Obsah stránky

<h1> - <h6>

Popis:
Nadpisy různých úrovní(heading).

<h1>

je nejdůležitější (hlavní nadpis),

<h6>

nejméně důležitý.


Jak se využívá:
Používají se pro strukturování obsahu. Pomáhají uživatelům i vyhledávačům pochopit hierarchii stránky. Na stránce by měl být obvykle jen jeden

<h1>

.

Ukázka Kódu

<h1>Hlavní nadpis</h1>

<h2>Podnadpis</h2>

<h3>Menší sekce</h3>

<p>

Popis:
Odstavec textu (paragraph).


Jak se využívá:
Používá se pro běžný textový obsah. Prohlížeč automaticky přidává mezery mezi odstavci.

Ukázka Kódu

<p>Toto je odstavec textu na stránce.</p>

<p>Další odstavec s informacemi.</p>

<div>

Popis:
Univerzální blokový element bez vlastního významu (tzv. „kontejner“).


Jak se využívá:
Používá se hlavně pro rozvržení stránky (layout) a stylování pomocí CSS nebo práci s JavaScriptem. Neměl by nahrazovat sémantické prvky jako

<section>

nebo

<main>

.

Ukázka Kódu

<div class="box">

<p>Obsah v kontejneru</p>

</div>

<a>

Popis:
Slouží k vytváření odkazů (hyperlinků), které uživatele přesměrují na jinou stránku nebo část webu.


Jak se využívá:
Používá se s atributem

href

, který určuje cílovou adresu. Může odkazovat na jiný web, soubor nebo konkrétní část stránky.

Ukázka Kódu

Přesměrovat v tomto okně:

<a href= "https://www.google.com"> Přejít na Google </a>


Otevření odkazu v novém okně:

<a href= "https://www.google.com" target="_blank"> Otevřít Google </a>

<img>

Popis:
Slouží k zobrazení obrázku na stránce.


Jak se využívá:
Používá se s atributem src (cesta k obrázku) a alt (alternativní text pro přístupnost a případ, kdy se obrázek nenačte).

Ukázka Kódu

<img src="obrazek.jpg" alt="Popis obrázku">

<br>

Popis:
Zalomí řádek (udělá nový řádek bez vytvoření nového odstavce).


Jak se využívá:
Používá se pro krátké zalomení textu (např. adresa, básně). Neměl by se používat pro oddělování odstavců.

Ukázka Kódu

<p>

Jméno: Jan Novák<br>

Email: jan@email.cz

</p>

Seznamy

<ul>

Popis:
Neuspořádaný seznam (unordered list) – položky nejsou číslované, ale mají odrážky.


Jak se využívá:
Používá se pro výpis položek, kde nezáleží na pořadí (např. seznam funkcí, ingrediencí).

Ukázka Kódu

<ul>

<li>Jablko</li>

<li>Banán</li>

<li>Pomeranč</li>

</ul>

<ol>

Popis:
Uspořádaný seznam (ordered list) – položky jsou číslované.


Jak se využívá:
Používá se tam, kde pořadí hraje roli (např. postup, instrukce).

Ukázka Kódu

<ol>

<li>Zapni počítač</li>

<li>Otevři prohlížeč</li>

<li>Navštiv stránku</li>

</ol>

<li>

Popis:
Jednotlivá položka seznamu.


Jak se využívá:
Používá se uvnitř <ul> nebo <ol> pro definování konkrétních položek.

Ukázka Kódu

<ul>

<li>První položka</li>

<li>Druhá položka</li>

</ul>

<dl>

Popis:
Definiční seznam (description list) – používá se pro dvojice termín + popis.


Jak se využívá:
Hodí se pro slovníky, pojmy a jejich vysvětlení nebo seznamy vlastností.

Ukázka Kódu

<dl>

<dt>HTML</dt>

<dd>Jazyk pro tvorbu webových stránek</dd>

</dl>

<dt>

Popis:
Termín (název) v definičním seznamu.


Jak se využívá:
Používá se uvnitř

<dl>

jako označení pojmu.

Ukázka Kódu

<dl>

<dt>CSS</dt>

<dd>Stylování webu</dd>

</dl>

<dd>

Popis:
Popis nebo definice k termínu.


Jak se využívá:
Používá se uvnitř

<dl>

jako vysvětlení k

<dt>

.

Ukázka Kódu

<dl>

<dt>JavaScript </dt>

<dd>Programovací jazyk pro interaktivitu</dd>

</dl>

Formuláře

<form>

Základní obal pro formulář. Umožňuje uživateli odeslat data (např. přihlašovací údaje, zprávy).


Jak se využívá:
Používá se s atributy jako action (kam se data pošlou) a method (způsob odeslání – GET nebo POST).

Ukázka Kódu

<form action="/odeslat" method="post">

<!-- formulářové prvky -->

</form>

Vstupní pole pro uživatele.


Jak se využívá:
Používá se pro zadávání dat (text, email, heslo atd.). Typ pole se určuje atributem

.

Ukázka Kódu

<input type="email" placeholder="Email">

<input type="password" placeholder="Heslo">

<label>

Popisek k formulářovému poli.


Jak se využívá:
Propojuje se s

<label>

pomocí atributu

(který odpovídá

id

inputu). Zlepšuje přístupnost a kliknutí na text aktivuje pole.

<input id="jmeno" type="text">

<button>

Jak se využívá:

type="submit"

pro odeslání dat.

Ukázka Kódu

Určuje název stránky, který se zobrazuje v záložce prohlížeče.


Jak se využívá:
Je důležitý pro uživatele i SEO (vyhledávače). Každá stránka by měla mít unikátní a výstižný název.

Ukázka Kódu

<meta>

Popis:
Slouží k definování metadat o stránce (např. znaková sada, popis stránky, responzivita).


Jak se využívá:
Používá se pro technická nastavení a informace pro prohlížeče a vyhledávače.

Ukázka Kódu

<meta charset="UTF-8">

<meta name="viewport" content="width=device-width, initial-scale=1.0">

<link>

Popis:
Propojuje HTML dokument s externími soubory (nejčastěji CSS).


Jak se využívá:
Používá se pro načtení stylů, ikon (favicon) nebo fontů.

Ukázka Kódu

<style>

Umožňuje zapisovat CSS přímo do HTML dokumentu.

<link>

).

Ukázka Kódu

<style>

body {

background-color: lightgray;

}

p {

color: blue;

}

</style>

Úvod

Jak propojit HTML s CSS

Jsou tři způsoby, jak propojit CSS s HTML:


  1. Použít externí css soubor a propojit ho pomocí elementu <link> v hlavičce HTML souboru
  2. Použít <style> element v hlavičce html souboru
  3. Použít atribut style v HTML elementu

Ukázka

  1. 1. Externí:

    <head>

    <link rel="stylesheet" href="mystyle.css">

    </head>

  2. 2. V Hlavičce:

    <head>

    <style>

    body {

     background-color: blue;

    }

    </style>

    </head>

  3. 3. V Elementu:

    <p style="color:red;"> Text </p>

Syntax a Selektory

Syntax

Pravidlo CSS se skládá ze selektoru a deklaračního bloku:


  • Selektor ukazuje, jakou třídu, id nebo element chcete stylovat.
  • Blok deklarací obsahuje deklarace oddělené středníky.
  • Deklarace obsahuje vlastnost CSS a její hodnotu oddělenou dvojtečkou.
  • Bloky deklarací jsou uzavřeny do složených závorek.

Ukázka

Selektor

body

Vlastnost : Hodnota

{background-color: blue;}

Selektory

CSS selektory se používají k výběru prvků HTML, které chcete stylovat.

Níže je seznam několika základních typů:


  • Selektor elementu, který vybírá HTML prvky na základě jejich názvu.
  • ID selektor, který používá atribut id HTML elementu k výběru konkrétního elementu. ID elementu je v rámci stránky jedinečné.
  • Selektor Třídy vybírá prvky HTML se specifickým atributem třídy.
  • Univerzální selektor, který vybírá všechny elementy na stránce.

Selektory je také možné seskupovat. Oddělujeme je čárkou.

Ukázka

  • Dle Elementu:

    element {}

  • Dle ID:

    #id {}

  • Dle Třídy:

    .class {}

  • Univerzální:

    * {}


  • Seskupené selektory

    selektor1, selektor2, selektor3, ... {}

Základní vlastnosti

Barvy a Pozadí

V CSS se barvy určují pomocí předdefinovaného názvu barvy nebo pomocí hodnoty RGB, HEX, HSL, RGBA nebo HSLA

Můžeme upravit například barvu:


  • Pozadí
  • Textu
  • Ohraničení

Seznam všech předdefinovaných barev

Ukázka

  • Barva Pozadí:

    background-color:blue

  • Barva Textu:

    color:blue

  • Barva Ohraničení:

    border:2px solid blue


  • Možnosti definování barev:

    color:blue

    color:rgb(255, 99, 71)

    color:#001047

    color:hsl(147, 50%, 47%)

    V těchto je také možné definovat průhlednost:

    color:rgba(255, 99, 71, 0.5)

    color:hsla(9, 100%, 64%, 0.5)

Border

Vlastnosti ohraničení umožňují nastavit styl, velikost a barvu ohraničení.

Styly ohraničení:


  • dotted - Tečkované ohraničení
  • dashed - Přerušované ohraničení
  • solid - Plné ohraničení
  • double - Dvojité ohraničení
  • groove - 3D drážkované ohraničení
  • ridge - 3D vroubkované ohraničení
  • inset - 3D zastouplé ohraničení
  • outset - 3D vystouplé ohraničení
  • none - Bez ohraničení
  • hidden - Skryté ohraničení

Styly je možné kombinovat.

Šířku ohraničení je možné nastavit na specifickou hodnotu (např. px) nebo pomocí tří předdefinovaných hodnot: thin, medium a thick

Styly a šířky mohou mít jednu až čtyři hodnoty (Nahoře, Vpravo, Dole, Vlevo).

Je také možné specifikovat jednu stranu ohraničení. Např. border-top-radius


Barvy ohraničení jsou vysvětleny v sekci barvy.

Ukázka

  • Zápis v kódu:

    border-style:dotted

    border-style:dotted solid double dashed

    border-width:medium

    border-width:25px 10px 4px 35px

  • Ukázka:

    dotted dashed solid double

    groove

    ridge

    inset

    outset

Zakulacené rohy

Zakulacené rohy můžeme vytvořit pomocí vlastnosti border-radius

Může mít jednu až čtyři hodnoty (Nahoře, Vpravo, Dole, Vlevo).


Pro jednotlivé rohy lze také použít the border-top-left-radius, border-top-right-radius, border-bottom-right-radius a border-bottom-left-radius

Ukázka

  • border-radius:5px

    border-radius:5px 10px 15px 10px

Výška a Šířka

Tyto vlastnosti nastavují, jako výšku a šířku element bude mít.

Mají následující hodnoty:


  • auto - Základní hodnota. Prohlížeč spočítá výšku a šířku.
  • Specifická hodnota (např. px)
  • % - Procenta
  • initial - Nastaví šířku nebo výšku na základní hodnotu.
  • inherit - Výška nebo šířka bude převzata z nadřazené hodnoty.

Ukázka

  • Výška:

    height:auto

  • Šířka:

    width:auto

Texty a Fonty

Texty

U textu můžeme nastavit barvu, zarovnání a dekoraci.

O barvě textu je možné se více dozvědět v sekci barvy.

Možnosti zarovnání textu:


  • left
  • right
  • center
  • justify

Při nastavení „justify“ se každý řádek natáhne tak, aby měl stejnou šířku a levý a pravý okraj byly rovné.

Box Model

Box Model

V CSS se termín „box model“ používá, když se mluví o webdesignu a rozvržení.

Skládá se ze čtyř částí (od nejvnitřnější k nejvnější):


  • Content - Obsah (Obrázky, text, atd.)
  • Padding - Prázdná oblast mezi obsahem a ohraničením (Border)
  • Border - Ohraničení obsahu a paddingu
  • Margin - Prázdná oblast okolo ohraničení.

Ukázka

Content, Padding, Border, Margin

Margin a Padding

Margin se používá k vytvoření prostoru kolem prvků. Definují vzdálenost mezi okrajem elementu a okolními elementy.


Padding se používá k vytvoření prostoru kolem obsahu elementu, uvnitř definovaných okrajů.


Margin a Padding je také možné nastavit na jednotlivé strany:

  • margin/padding-top
  • margin/padding-left
  • margin/padding-right
  • margin/padding-bottom

Position

Static

Výchozí nastavení pozice.


Staticky umístěné prvky nejsou ovlivněny vlastnostmi top, bottom, left a right.


Prvky se statickou pozicí jsou umístěny dle normálního toku stránky.

Ukázka

  • Lorem ipsum dolor sit amet, consectetur adipiscing elit.


    position: static


    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

Relative

Prvek je umístěn vzhledem ke své normální pozici v dokumentu.


Nastavení vlastností top, right, bottom a left způsobí, že se prvek posune mimo svou normální polohu.

Ukázka

  • Lorem ipsum dolor sit amet, consectetur adipiscing elit.


    position: relative; left: 30px;


    Lorem ipsum dolor sit amet, consectetur adipiscing elit.

Fixed

Prvek je umístěn relativně vzhledem k zobrazovacímu oknu, což znamená, že vždy zůstává na stejném místě, i když je stránka posunuta.


Vlastnosti top, right, bottom a left se používají k nastavení konečné polohy elementu.

Ukázka

  • Použitím css kódu níže docílíte elementu, který se bude držet v pravém dolním rohu stránky.

    position: fixed;bottom: 0;right: 0;width: 100px; border: 2px solid black;

Absolute

Prvek je umístěn vzhledem k nejbližšímu umístěnému předkovi s jinou pozicí než static.


Pokud ale element s absolutní pozicií nemá žádné předky, použije tělo dokumentu a pohybuje se spolu s posouváním stránky.


Pozor: Prvky s absolutní polohou se mohou překrývat s jinými prvky.

Ukázka

  • relative

    absolute

  • Kód relative:

    position: relative;width: 192px;height: 192px;border: 3px solid black;

  • Kód absolute:

    position: absolute;width: 112px;height: 112px;right: 4;bottom: 4;background-color: blue;color: white;

Sticky

Prvek se přepíná mezi pozicí relative a fixed v závislosti na pozici.


Sticky element je umístěn relativně, dokud není dosaženo určité pozice posunu. Poté se na tomto místě "zasekne" a funguje jako fixed.


Pozor: Aby umístění fungovalo, musíte zadat alespoň jednu z vlastností top, right, bottom nebo left

Ukázka

  • Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo.

    position: sticky;

    Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo. Atqui causae gloriatur ius te, id agam omnis evertitur eum.

    Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo. Atqui causae gloriatur ius te, id agam omnis evertitur eum.

    Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo. Atqui causae gloriatur ius te, id agam omnis evertitur eum.

    position: sticky;top: 0;background-color: blue;color: white;

Patří sem vlastnosti top, right, bottom, a left, které odsadí prvek o zadanou vzdálenost od určitého kraje elementu.


Tyto vlastnosti fungují pouze na prvcích s position nastaveným na relative, absolute, fixed nebo sticky.

Display

Display

Důležitá vlastnost pro řízení rozvržení. Určuje, zda se s HTML elementem zachází jako s blokovým nebo inline elementem.


Každý element HTML má výchozí zobrazovanou hodnotu v závislosti na typu elementu. Pro většinu elementů je to block nebo inline.


Blokové elementy:


Blokový element pokaždé začíná na novém řádku a zabírá celou dostupnou šířku.

Příklady:


  • <div>
  • <section>
  • <header>
  • <footer>
  • <p>
  • A další ...

Inline elementy:


Inline element nezačíná na novém řádku a zabírá pouze tolik šířky, kolik je potřeba.

Příklady:


  • <span>
  • <a>
  • A další ...

Hodnoty vlastonsti display:


  • block - začíná na novém řádku a zabírá celou dostupnou šířku
  • inline - nezačíná na novém řádku a zabírá pouze tolik šířky, kolik je potřeba
  • inline-block - něco mezi inline a block. Element je formátovaný jako inline, ale lze u něj použít výšku, šířku, pading a margin.
  • flex - více v sekci flexbox
  • grid - více v sekci grid
  • none - element je úplně skryt a nezabítá žádné místo

Ukázka

  • Block:

    display: block;width: 192px; padding: 16px;border: 2px solid blue;

    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

  • Inline:

    display: inline; padding: 16px;border: 2px solid blue;

    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

    </script>

Základy JavaScriptu

Základní datové typy

Datové typy určují druh dat, například text nebo čísla. Různé typy dat určují, jaké operace s nimi můžeme provádět. V Javascriptu je mnoho různých datových typů, teď se ale zaměříme na ty nejznámější a nejpoužívanější:


  1. 1. number - nejběžnější datový typ pro čísla, můžou se s ním provádět matematické operace
  2. 2. string je určený pro jakékoliv znaky, používá se tedy při práci s textem. Dává se do uvozovek (""), které značí že se jedná o string
  3. 3. boolean - datový typ používanější nejčastěji u podmínek, uchovává hodnoty true (pravdivé) nebo false (nepravdivé)

Ukázka Kódu

  1. 1. Příklady numberu:

    25

    0

    -9.68


  2. 2. Příklady stringu:

    "Ahoj"

    "Jak se máš?"

    Skvěle!   // toto není platný string


  3. 3. Booleany:

    true

    false

Komentáře

Komentáře slouží k vkládání vlastních poznámek do programu, mohou sloužit k lepší orientaci v kódu (používáme je občas také v této příručce :)). Text označený jako komentář program nespustí.


Jednoduché komentáře značíme dvěmi lomítky (//) za kterými napíšeme svůj komentář - ten lze ale zapsat pouze na jeden řádek. Víceřádkové komentáře začínají lomítkem a hvězdičkou (/*) a končí hvězdičkou a lomítkem (*/), přičemž náš komentář vložíme mezi ně.

Ukázka Kódu

  1. 1. Jednoduchý komentář

    // toto je komentář na jeden řádek


  2. 2. Víceřádkový komentář

    /* Tento komentář funguje..

     ..na více řádcích!*/

Proměnné

Proměnné slouží k ukládání dat pod vlastními názvy, se kterými lze potom v programu dále pracovat (např. text, čísla, seznamy). V JavaScriptu existují dva základní druhy proměnných: let a const.


  1. u proměnné let se hodnota může měnit.

  2. u proměnné const se hodnota po jejím deklarování změnit nemůže.


Po klíčových slovech let nebo const následuje název proměnné jakýkoli si zvolíte, znaménko '=' a hodnotu kterou jí chcete přiřadit. Středníkem (;) vždy zakončujeme příkaz.

Ukázka Kódu

  1. 1. Proměnná let:

    let jmeno = "Jan";

    jmeno = "Petr";


  2. 2. Proměnná const:

    const vek = 25;

    vek = 30;   // vypíše chybu

console.log()

Console.log() je funkce, která vypisuje hodnoty do vývojářské konzole v prohlížeči. Používá se hlavně při učení a ladění kódu – můžete si tak ověřit, co se děje v programu.


Mezi závorky vždy vložíme název proměnné či jakoukoli jinou hodnotu kterou chceme vypsat.

Ukázka Kódu

  1. 1. Vypsání vlastní hodnoty

    console.log(​"Ukázkový text");


  2. 2. Vypsání hodnoty z proměnné

    const vesnice = "Brno";

    console.log(​vesnice);

Řízení toku programu

Podmínky

Podmínky umožňují spouštět různé části kódu podle toho, jestli je nějaká podmínka splněná.

Používají se všude tam, kde program musí „rozhodovat“, např. kontrola věku, přihlášení...


Po slovu if následuje v závorkách podmínka a v složených závorkách kód který se spustí pokud je podmínka platná. Pro více podmínek se používá (ale není povinný) příkaz else if, a potom else pokud žádná z podmínek nemá být pravdivá.

Ukázka Kódu

let vek = 18;

if (vek => 18) {

 console.log(​"Přístup povolen");

} else if (vek > 120) {

 console.log(​"Zadejte platný věk");

} else {

 console.log(​"Nejsi plnoletý, přístup odepřen");

}

Cyklus (for)

Cyklus (anglicky "loop") opakuje určitý blok kódu vícekrát.

Používá se např. pro procházení pole (array) nebo opakování akce po určitý počet pokusů.


Podobně jako if podmínky začíná klíčovým for za kterým v závorce následují tři výrazy oddělené středníkem:


  1. v prvním výrazu se vytvoří proměnná s nějakým počátečním číslem, která bude sloužit jako počítač (angl. counter)

  2. v druhém výrazu se nastaví podmínka která určí, kolikrát má program daný kód opakovat

  3. ke třetímu výrazu se v každém kole for cyklu přičte k počítací proměnné +1


Po definování těchto tří výrazů potom v složených závorkách následuje blok kódu který má for cyklus opakovat.

Ukázka Kódu

for (let i = 0; i < 3; i++) {

 console.log(​"Opakování: ", i);

}

Funkce

Funkce

Funkce je blok kódu, který je možné "zavolat" kdykoli je potřeba. Pomáhá rozdělit program na menší části.

Používá se pro znovupoužití kódu a lepší organizaci.


Po slovu function následuje jméno funkce, jaké si zvolíte a v složených závorkách váš kód.

Po jménu funkce můžete přidat takzvané parametry, které slouží jako vstupní data pro funkci zvenčí čímž se zvyšuje flexibilita a znovupoužitelnost funkcí, nejsou ale povinné.


Aby se funkce spustila, je potřeba ji potom "zavolat" jejím jménem a případně parametry.

Ukázka Kódu

  1. 1. Základní funkce bez parametrů

    function pozdravJarmi​lu() {

     console.log(​"Ahoj Jarmilo");

    }


    pozdravJarmi​lu();


  2. 2. Funkce s parametry

    function pozdrav(jmeno) {

     console.log(​"Ahoj " + jmeno);

    }


    pozdrav(​"Jarmilo");

    pozdrav(​"Pavle");

Arrow funkce

Arrow funkce poskytují modernější a kratší zápis funkce. Využívá se často u jednoduchých funkcí nebo jako callback (např. u událostí).


Arrow funkce na rozdíl od klasických funkcí automaticky ukládají výslednou hodnotu do proměnné. Za proměnnou následují (pokud nějaké) parametry a po šipce "=>" v složených závorkách už píšete váš kód.

Ukázka Kódu

const pozdrav = (jmeno) => {

 console.log(​"Ahoj " + jmeno);

};


pozdrav(​"Jano");

Datové struktury

Pole

Pole (angl. "array") je seznam hodnot uložených v jedné proměnné. Používá se pro práci s více daty, např. seznam uživatelů, produktů...


Zapisuje se jako soubor hodnot v hranatých závorkách oddělených čárkou. Pokud chcete z pole získat nějakou hodnotu, tak napíšete název pole a v hranatých závorkách číslo pořadí (indexu), v jakém hodnota v tom poli je.


⚠ POZOR!

V programování se počítání indexu začíná od nuly, takže např. druhá položka v pořadí má index 1, třetí index 2, čtvrtá index 3 atd...

Ukázka Kódu

let ovoce = ["jablko", "banán", "pomeranč"];

console.log(​ovoce[1]);   // vypíše "banán"

Objekt

Objekty ukládají data ve formě klíč-hodnota, přičemž jeden objekt může mít libovolný počet vlastností.

Používají se tedy pro reprezentaci složitějších dat (např. uživatel s více vlastnostmi).


Objekty se v Javascriptu ukládají jako jeden soubor vlastností do proměnných. Po vytvoření proměnné ve složených závorkách začínáme psát vlastnosti: její název, dvojtečku a mezeru, a hodnotu vlastnosti. Více vlastností oddělujeme čárkou.


Pro získání hodnoty vlastnosti z objektu použijeme výraz ve formátu "názevObjektu.náz​evVlastnosti". Tomuto konceptu se také říká Objektově Orientované Programování (OOP).

Ukázka Kódu

let uzivatel = {

 jmeno: "Tomáš",

 vek: 25

};


console.log(​uzivatel.vek);

Vlastnosti

document.query​Selector()

document.query​Selector() vybírá první HTML element, který odpovídá zadanému CSS selektoru.

Používají se pro propojení Javascriptu s HTML (tzv. práce s DOM).


Syntax je zde velmi jednoduchý: po příkazu document.querySel​ector následuje v závorkách a uvozovkách název HTML elementu který hledáme.

Ukázka Kódu

let nadpis = document.query​Selector(​"h1");

textContent

TextContent je vlastnost, která nastavuje nebo čte text uvnitř elementu. Používá se pro dynamickou změnu textu na stránce.

Po vybrání konkrétního HTML elementu změníte jeho text jednoduše přiřazením nové hodnoty.

Ukázka Kódu

let p = document.qu​erySelec​tor("p");

p.textCo​ntent = "Nový text";

Ukázka Kódu

div.style​.backgroun​dColor = "blue";

Události

addEvent​Listener()

Čeká na událost (např. kliknutí, stisk klávesy) a spustí vybranou funkci. Používá se pro vytváření dynamických prvků.


Opět nejdříve vyberete element který chcete aby se za dané události zachoval jinak a:

  1. 1. v závorkách nejprve definujete na jakou událost se má funkce spustit (např. kliknutí), oddělíte čárkou
  2. 2. definujete vlastní funkci: co chcete, aby se danému elementu stalo (nebo zavoláte již existující funkci)

Ukázka Kódu

let button = document.qu​erySelector(​"button");

button.add​EventListe​ner("click", () => {

 console.log(​"Klik!");

});

setTimeout()

Spustí funkci po určitém čase (v milisekundách).

Používá se pro zpožděné akce, např. notifikace.


Po klíčových slovech setTimeout do závorek nejprve napíšete (nebo zavoláte) funkci která řekne co se má stát, oddělíte čárkou a napíšete za kolik milisekund se má událost spustit.

Ukázka Kódu

setTimeout(() => {

 console.log(​"Hotovo");

}, 2000);   // zpozdí se o 2 sekundy

setInterval

Funkce, která se opakuje v pravidelných intervalech.

Používá se pro časovače nebo opakované akce.

Ukázka Kódu

setInterval(() => {

 console.log(​"Běží...");

}, 1000);   // spustí se každou 1 sekundu
