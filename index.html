Úvod

Jak propojit HTML s CSS

Jsou tři způsoby, jak propojit CSS s HTML:


  1. Použít externí css soubor a propojit ho pomocí elementu <link> v hlavičce HTML souboru
  2. Použít <style> element v hlavičce html souboru
  3. Použít atribut style v HTML elementu

Ukázka

  1. 1. Externí:

    <head>

    <link rel="stylesheet" href="mystyle.css">

    </head>

  2. 2. V Hlavičce:

    <head>

    <style>

    body {

     background-color: blue;

    }

    </style>

    </head>

  3. 3. V Elementu:

    <p style="color:red;"> Text </p>

Syntax a Selektory

Syntax

Pravidlo CSS se skládá ze selektoru a deklaračního bloku:


  • Selektor ukazuje, jakou třídu, id nebo element chcete stylovat.
  • Blok deklarací obsahuje deklarace oddělené středníky.
  • Deklarace obsahuje vlastnost CSS a její hodnotu oddělenou dvojtečkou.
  • Bloky deklarací jsou uzavřeny do složených závorek.

Ukázka

Selektor

body

Vlastnost : Hodnota

{background-color: blue;}

Selektory

CSS selektory se používají k výběru prvků HTML, které chcete stylovat.

Níže je seznam několika základních typů:


  • Selektor elementu, který vybírá HTML prvky na základě jejich názvu.
  • ID selektor, který používá atribut id HTML elementu k výběru konkrétního elementu. ID elementu je v rámci stránky jedinečné.
  • Selektor Třídy vybírá prvky HTML se specifickým atributem třídy.
  • Univerzální selektor, který vybírá všechny elementy na stránce.

Selektory je také možné seskupovat. Oddělujeme je čárkou.

Ukázka

  • Dle Elementu:

    element {}

  • Dle ID:

    #id {}

  • Dle Třídy:

    .class {}

  • Univerzální:

    * {}


  • Seskupené selektory

    selektor1, selektor2, selektor3, ... {}

Základní vlastnosti

Barvy a Pozadí

V CSS se barvy určují pomocí předdefinovaného názvu barvy nebo pomocí hodnoty RGB, HEX, HSL, RGBA nebo HSLA

Můžeme upravit například barvu:


  • Pozadí
  • Textu
  • Ohraničení

Seznam všech předdefinovaných barev

Ukázka

  • Barva Pozadí:

    background-color:blue

  • Barva Textu:

    color:blue

  • Barva Ohraničení:

    border:2px solid blue


  • Možnosti definování barev:

    color:blue

    color:rgb(255, 99, 71)

    color:#001047

    color:hsl(147, 50%, 47%)

    V těchto je také možné definovat průhlednost:

    color:rgba(255, 99, 71, 0.5)

    color:hsla(9, 100%, 64%, 0.5)

Border

Vlastnosti ohraničení umožňují nastavit styl, velikost a barvu ohraničení.

Styly ohraničení:


  • dotted - Tečkované ohraničení
  • dashed - Přerušované ohraničení
  • solid - Plné ohraničení
  • double - Dvojité ohraničení
  • groove - 3D drážkované ohraničení
  • ridge - 3D vroubkované ohraničení
  • inset - 3D zastouplé ohraničení
  • outset - 3D vystouplé ohraničení
  • none - Bez ohraničení
  • hidden - Skryté ohraničení

Styly je možné kombinovat.

Šířku ohraničení je možné nastavit na specifickou hodnotu (např. px) nebo pomocí tří předdefinovaných hodnot: thin, medium a thick

Styly a šířky mohou mít jednu až čtyři hodnoty (Nahoře, Vpravo, Dole, Vlevo).

Je také možné specifikovat jednu stranu ohraničení. Např. border-top-radius


Barvy ohraničení jsou vysvětleny v sekci barvy.

Ukázka

  • Zápis v kódu:

    border-style:dotted

    border-style:dotted solid double dashed

    border-width:medium

    border-width:25px 10px 4px 35px

  • Ukázka:

    dotted dashed solid double

    groove

    ridge

    inset

    outset

Zakulacené rohy

Zakulacené rohy můžeme vytvořit pomocí vlastnosti border-radius

Může mít jednu až čtyři hodnoty (Nahoře, Vpravo, Dole, Vlevo).


Pro jednotlivé rohy lze také použít the border-top-left-radius, border-top-right-radius, border-bottom-right-radius a border-bottom-left-radius

Ukázka

  • border-radius:5px

    border-radius:5px 10px 15px 10px

Výška a Šířka

Tyto vlastnosti nastavují, jako výšku a šířku element bude mít.

Mají následující hodnoty:


  • auto - Základní hodnota. Prohlížeč spočítá výšku a šířku.
  • Specifická hodnota (např. px)
  • % - Procenta
  • initial - Nastaví šířku nebo výšku na základní hodnotu.
  • inherit - Výška nebo šířka bude převzata z nadřazené hodnoty.

Ukázka

  • Výška:

    height:auto

  • Šířka:

    width:auto

Texty a Fonty

Texty

U textu můžeme nastavit barvu, zarovnání a dekoraci.

O barvě textu je možné se více dozvědět v sekci barvy.

Možnosti zarovnání textu:


  • left
  • right
  • center
  • justify

Při nastavení „justify“ se každý řádek natáhne tak, aby měl stejnou šířku a levý a pravý okraj byly rovné.

Je několik možností dekorace textu:


  • overline
  • line-through
  • underline

Můžeme také změnit barvu, styl nebo tloušťku dekorace.

Styly dekorace:


  • solid
  • double
  • dotted
  • dashed
  • wavy

Ukázka

  • Zarovnání textu:

    text-align:left

    text-align:right

    text-align:center

  • Dekorace textu:

    text-decoration-line:overline

    text-decoration-line:line-through

    text-decoration-line:underline

  • Vlastnosti dekorace textu:

    text-decoration-color:black

    text-decoration-style:wavy

    text-decoration-thickness:5px

Fonty

V CSS můžeme také nastavit vlastní písmo.


Je možné nastavit několik písem jako „záložní“ systém. Pokud prohlížeč nepodporuje první písmo, zkusí použít další. Názvy písem by měly být odděleny čárkou.


Dále lze u písem nastavit jejich velikost a také styl (normal,italic,...)

Ukázka

  • Nastavení písma:

    font-family: "Times New Roman", Times, serif

  • Styl písma:

    font-style: italic

  • Velikost písma:

    font-size: 16px

Box Model

Box Model

V CSS se termín „box model“ používá, když se mluví o webdesignu a rozvržení.

Skládá se ze čtyř částí (od nejvnitřnější k nejvnější):


  • Content - Obsah (Obrázky, text, atd.)
  • Padding - Prázdná oblast mezi obsahem a ohraničením (Border)
  • Border - Ohraničení obsahu a paddingu
  • Margin - Prázdná oblast okolo ohraničení.

Ukázka

Content, Padding, Border, Margin

Margin a Padding

Margin se používá k vytvoření prostoru kolem prvků. Definují vzdálenost mezi okrajem elementu a okolními elementy.


Padding se používá k vytvoření prostoru kolem obsahu elementu, uvnitř definovaných okrajů.


Margin a Padding je také možné nastavit na jednotlivé strany:

  • margin/padding-top
  • margin/padding-left
  • margin/padding-right
  • margin/padding-bottom

Nebo pomocí čtyř hodnot. (top,right,bottom,left)

Ukázka

  • Margin:

    margin:20px

  • Padding:

    padding:20px

  • Specifické nastavení:

    margin:12px 4px 2px 4px

Position

Static

Výchozí nastavení pozice.


Staticky umístěné prvky nejsou ovlivněny vlastnostmi top, bottom, left a right.


Prvky se statickou pozicí jsou umístěny dle normálního toku stránky.

Ukázka

  • Lorem ipsum dolor sit amet, consectetur adipiscing elit.


    position: static


    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

Relative

Prvek je umístěn vzhledem ke své normální pozici v dokumentu.


Nastavení vlastností top, right, bottom a left způsobí, že se prvek posune mimo svou normální polohu.

Ukázka

  • Lorem ipsum dolor sit amet, consectetur adipiscing elit.


    position: relative; left: 30px;


    Lorem ipsum dolor sit amet, consectetur adipiscing elit.

Fixed

Prvek je umístěn relativně vzhledem k zobrazovacímu oknu, což znamená, že vždy zůstává na stejném místě, i když je stránka posunuta.


Vlastnosti top, right, bottom a left se používají k nastavení konečné polohy elementu.

Ukázka

  • Použitím css kódu níže docílíte elementu, který se bude držet v pravém dolním rohu stránky.

    position: fixed;bottom: 0;right: 0;width: 100px; border: 2px solid black;

Absolute

Prvek je umístěn vzhledem k nejbližšímu umístěnému předkovi s jinou pozicí než static.


Pokud ale element s absolutní pozicií nemá žádné předky, použije tělo dokumentu a pohybuje se spolu s posouváním stránky.


Pozor: Prvky s absolutní polohou se mohou překrývat s jinými prvky.

Ukázka

  • relative

    absolute

  • Kód relative:

    position: relative;width: 192px;height: 192px;border: 3px solid black;

  • Kód absolute:

    position: absolute;width: 112px;height: 112px;right: 4;bottom: 4;background-color: blue;color: white;

Sticky

Prvek se přepíná mezi pozicí relative a fixed v závislosti na pozici.


Sticky element je umístěn relativně, dokud není dosaženo určité pozice posunu. Poté se na tomto místě "zasekne" a funguje jako fixed.


Pozor: Aby umístění fungovalo, musíte zadat alespoň jednu z vlastností top, right, bottom nebo left

Ukázka

  • Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo.

    position: sticky;

    Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo. Atqui causae gloriatur ius te, id agam omnis evertitur eum.

    Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo. Atqui causae gloriatur ius te, id agam omnis evertitur eum.

    Lorem ipsum dolor sit amet, illum definitiones no quo, maluisset concludaturque et eum, altera fabulas ut quo. Atqui causae gloriatur ius te, id agam omnis evertitur eum.

  • Kód:

    position: sticky;top: 0;background-color: blue;color: white;

Position Offsets

Patří sem vlastnosti top, right, bottom, a left, které odsadí prvek o zadanou vzdálenost od určitého kraje elementu.


Tyto vlastnosti fungují pouze na prvcích s position nastaveným na relative, absolute, fixed nebo sticky.

Ukázka

  • top 0;

    left: 5;

    right 10;

    bottom: 0;

Z-index

Určuje, který prvek by měl být umístěn před nebo za ostatními prvky.


Prvek může mít kladný nebo záporný z-index.


Pozor: funguje pouze na pozicovaných prvcích a položkách flex boxu.

Ukázka

  • Bez z-indexu:

  • S z-index:

    z-index: 2;

    z-index: 1;

Display

Display

Důležitá vlastnost pro řízení rozvržení. Určuje, zda se s HTML elementem zachází jako s blokovým nebo inline elementem.


Každý element HTML má výchozí zobrazovanou hodnotu v závislosti na typu elementu. Pro většinu elementů je to block nebo inline.


Blokové elementy:


Blokový element pokaždé začíná na novém řádku a zabírá celou dostupnou šířku.

Příklady:


  • <div>
  • <section>
  • <header>
  • <footer>
  • <p>
  • A další ...

Inline elementy:


Inline element nezačíná na novém řádku a zabírá pouze tolik šířky, kolik je potřeba.

Příklady:


  • <span>
  • <a>
  • A další ...

Hodnoty vlastonsti display:


  • block - začíná na novém řádku a zabírá celou dostupnou šířku
  • inline - nezačíná na novém řádku a zabírá pouze tolik šířky, kolik je potřeba
  • inline-block - něco mezi inline a block. Element je formátovaný jako inline, ale lze u něj použít výšku, šířku, pading a margin.
  • flex - více v sekci flexbox
  • grid - více v sekci grid
  • none - element je úplně skryt a nezabítá žádné místo

Ukázka

  • Block:

    display: block;width: 192px; padding: 16px;border: 2px solid blue;

    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

  • Inline:

    display: inline; padding: 16px;border: 2px solid blue;

    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

  • Inline-Block:

    display: inline-block;width: 192px; padding: 16px;border: 2px solid blue;

    Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed eiusmod tempor incidunt ut labore et dolore magna aliqua.

Flexbox

Flexbox

Flexbox je model rozvržení pro uspořádání položek horizontálně nebo vertikálně v kontejneru flexibilním a responzivním způsobem.


Flexbox se používá pro jednorozměrné rozvržení s řádky nebo sloupci.

Flex Container

Nadřazený element (kontejner), kde je vlastnost display nastavena na flex nebo inline-flex.


Vlastnosti Flex Containeru:


  • display - musí být nastaven na flex nebo inline-flex
  • flex-direction - nastavuje směr položek flexboxu
  • flex-wrap - určuje, zda se mají položky flexboxu zalamovat, či nikoli
  • justify-content - zarovná položky flexboxu, pokud nevyužívají veškerý dostupný prostor na vodorovné ose
  • align-items - zarovná položky flexboxu, pokud nevyužívají veškerý dostupný prostor na vertikální ose

Grid

Grid

Grid nabízí systém rozvržení založený na mřížce s řádky a sloupci.


Usnadňuje návrh responzivní struktury rozvržení bez použití funkcí nebo umístění.

Grid Container

Grid Container

Nadřazený kontejner, který obsahuje jednu nebo více položek mřížky uspořádaných do sloupců a řádků.


Z elemntu se stane Grid, když je jeho vlastnost display nastavena na hodnotu grid nebo inline-grid.

Řádky a sloupce

Uvnitř gridu definujete počet a velikost sloupců a řádků mřížky.


K tomu se dají použít následující vlastnosti:


  • grid-template-columns - definuje počet a šířku sloupců v mřížce.
  • grid-template-rows - definuje počet a výšku řádků v mřížce.
  • grid-template-areas - definuje, jak zobrazit sloupce a řádky pomocí pojmenovaných položek mřížky.

Grid Items

Grid Items

Grid obsahuje jednu nebo více položek.


Všechny přímé podřízené prvky gridu se automaticky stanou položkami gridu.

Rozpětí / Velikost

Prvek mřížky se může rozprostírat přes více sloupců nebo řádků.


Pomocí následujících vlastností můžeme určit, kde má začít a skončit prvek mřížky:


  • grid-column-start - určuje, na kterém sloupci bude položka gridu začínat.
  • grid-column-end - určuje, na kterém sloupci bude položka gridu končit.
  • grid-row-start - určuje, na kterém řádku bude položka gridu začínat.
  • grid-row-end - určuje, na kterém řádku bude položka gridu končit.
  • grid-column - zkrácená vlastnost pro grid-column-start a grid-column-end.
  • grid-row - zkrácená vlastnost pro grid-row-start a grid-row-end.

Ukázka

  • grid-column-start: 1; grid-column-end: 3;

Align

Položky gridu lze zarovnat v rámci příslušných buněk gridu pomocí vlastností:


  • justify-self - určuje vodorovné zarovnání v buňce.
  • align-self - určuje svislé zarovnání v buňce.

Hodnoty justify-self:


  • auto
  • normal
  • stretch
  • center
  • start
  • end
  • left
  • right

Hodnoty align-self:


  • auto
  • normal
  • stretch
  • center
  • start
  • end
